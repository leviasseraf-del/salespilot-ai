# StreetFix SA (working title)

**Scope:** All nine South African provinces, with a municipality picker and official government directory fallback for smaller towns. This is an independent demo—not an official municipal service.

**Features:** mobile camera upload with local compression; optional GPS; issue categorisation by user; resident-selected province/municipality; verified official routes for City of Tshwane (Pretoria), City of Johannesburg (including JRA/Water), City of Ekurhuleni, City of Cape Town and eThekwini; draft email/copy/native sharing; on-device report and manually verified progress notes; installable PWA.

**Important limits:** Nothing is submitted automatically. No live computer-vision AI, municipal API integration, payment collection, public issue database, worker dispatch, subscriptions or repairs. Reports and compressed photos stored in the browser's localStorage on the device; clearing browser data deletes them. Sharing requires user's action. Contacts should be checked before use. Only authorized municipal services / contracted licensed parties may work on public infrastructure. Future multi-tenant cloud backend will require POPIA privacy measures and appropriate consents.

**Source directories / official channels:** South African Government local municipalities https://www.gov.za/about-government/contact-directory/provincial-local-government ; Tshwane https://www.tshwane.gov.za/?page_id=8184 ; Johannesburg https://jra.org.za and https://www.johannesburgwater.co.za ; Ekurhuleni https://www.ekurhuleni.gov.za/for-me/report-it/ ; Cape Town https://www.capetown.gov.za/city-connect/report/municipal-services-and-maintenance/submit-a-service-request-c3/ ; eThekwini https://www.durban.gov.za/ .

**Commercial model proposal (not operational):** free resident issue reporting; paid municipality/estate/property maintenance dashboards and approved private repair dispatch with transparently contracted charges. No fees on public complaints.
